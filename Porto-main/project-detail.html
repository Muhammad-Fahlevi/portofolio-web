Pengembangan Sistem Informasi Rental Mobil Dashboard Monitoring

Sistem Informasi Rental Mobil Dashboard Monitoring merupakan pengembangan dari sistem rental yang sebelumnya hanya melayani transaksi secara langsung (walk-in). Project ini dikembangkan untuk membantu digitalisasi operasional Randoom Rental Banjarbaru dengan menghadirkan pemesanan kendaraan secara online, dashboard monitoring, serta pengelolaan data kendaraan dan pelanggan dalam satu platform. Sebagai Full Stack Developer, saya bertanggung jawab mengembangkan fitur booking kendaraan, autentikasi pengguna, dashboard monitoring, serta integrasi GPS Tracker melalui REST API untuk menampilkan lokasi kendaraan secara real-time. Saya juga mengintegrasikan payment gateway agar proses pembayaran dapat dilakukan secara online dengan lebih praktis.

MenuKasir

MenuKasir merupakan aplikasi kasir berbasis web yang saya kembangkan sebagai individual project, terinspirasi dari pengalaman melihat sistem self-order di sebuah warung makan. Project ini menggabungkan konsep pemesanan mandiri (self-order) dan sistem kasir dalam satu platform, sehingga pelanggan dapat memesan makanan secara langsung, sementara kasir dan admin mengelola pesanan, transaksi, serta laporan penjualan melalui dashboard yang terintegrasi. Sebagai Full Stack Developer, saya merancang dan mengembangkan seluruh fitur aplikasi, mulai dari sistem autentikasi berdasarkan role (Customer, Kasir, dan Admin), manajemen menu dan kategori, pemesanan mandiri, pengelolaan transaksi, hingga dashboard yang menampilkan ringkasan aktivitas dan laporan penjualan. Sistem juga dilengkapi dengan perhitungan total pembayaran serta uang kembalian secara otomatis. Melalui project ini, saya memperdalam kemampuan membangun aplikasi web end-to-end, mulai dari perancangan alur sistem, pengembangan antarmuka dan backend, hingga memastikan pengalaman pengguna tetap sederhana, cepat, dan mudah digunakan.

Sistem Informasi Terpadu (SIMPADU)

SIMPADU merupakan aplikasi berbasis web yang dikembangkan dalam mata kuliah Project Based Learning (PBL) di Politeknik Negeri Banjarmasin. Pengembangan sistem dilakukan secara kolaboratif, di mana setiap kelompok bertanggung jawab mengerjakan modul yang berbeda sesuai pembagian tugas. Seluruh modul kemudian diintegrasikan menjadi satu sistem informasi terpadu yang mendukung aktivitas akademik, seperti pengelolaan jadwal perkuliahan, absensi, informasi mata kuliah, serta layanan akademik lainnya. Sebagai Frontend Developer, saya bertanggung jawab mengembangkan antarmuka pada modul yang menjadi tanggung jawab kelompok saya dengan mengutamakan desain yang responsif, mudah digunakan, dan konsisten. Saya juga berkolaborasi dengan anggota kelompok serta melakukan penyesuaian antarmuka agar hasil pengembangan dapat terintegrasi dengan modul yang dikerjakan oleh kelompok lain. Melalui project ini, saya memperoleh pengalaman bekerja dalam tim pada proyek berskala besar, memahami pentingnya koordinasi antar kelompok selama proses pengembangan, serta meningkatkan kemampuan dalam membangun antarmuka aplikasi web menggunakan Laravel, Blade, Tailwind CSS, dan JavaScript.
